STL Browser is a native Linux STL viewer based on fstl, adding a bottom thumbnail strip and explained appearance settings.

- Browse a folder with Left / Right arrows or clickable thumbnails.
- Five rendering styles: Classic fstl, Wireframe, Surface angle, Custom lighting, and Solid + wireframe.
- One-click Angle View with shaded triangle-edge overlays.
- Persistent color, light, projection, camera, and thumbnail preferences; hover explanations for every setting.
- On-demand rendering and lazy thumbnails with bounded caches.

**Linux x86_64 downloads:**

- `.deb`: built on Ubuntu 24.04; intended for Ubuntu 24.04 and newer. Install with `sudo apt install ./stl-browser_0.2.0_amd64.deb`.
- `.tar.gz`: the same dynamically linked application and desktop files. Requires glibc 2.39+, Qt 5.15 runtime libraries, and desktop OpenGL; it is not a self-contained AppImage.
- `showcase-models.zip`: Benchy, Stanford Bunny, and Utah Teapot, with their individual credits/licenses. Optional, separate from the app.
- `SHA256SUMS`: checksums for the downloads.

Other Linux distributions can build from source using the README instructions.
Screenshots in the README show the actual app, with credited free models.
